# Security Policy

## Supported Versions

Only the latest release on the `main` branch is currently supported for security updates.

| Version | Supported          |
| ------- | ------------------ |
| main    | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability within this project, please **DO NOT** open a public issue.

Instead, please report it via one of the following methods:
1. Use GitHub's [Private Vulnerability Reporting](../../security/advisories/new) feature on this repository.
2. Email the maintainer directly at `security@yourdomain.com`.

### What to Include in Your Report
* Description of the vulnerability and potential risk.
* Step-by-step instructions or proof-of-concept to reproduce the issue.
* Any suggested mitigations or patches.

You will receive an initial response within 48 hours.
